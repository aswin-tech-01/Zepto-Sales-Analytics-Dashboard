## 📊 Project Overview

An interactive **Zepto Sales Analytics Dashboard** developed in Microsoft Excel to transform transactional sales data into actionable business insights.

The project covers the complete analytics workflow — from **data cleaning and preparation to KPI development, PivotTable analysis, interactive visualizations, and dashboard design**.

The dashboard enables users to analyze sales performance across different **cities, product categories, payment methods, customer segments, and ordering time slots**.

---

## 🎯 Business Objective

The primary objective of this project is to provide a consolidated view of sales performance and customer purchasing behavior.

The dashboard is designed to answer key business questions such as:

* How much revenue is being generated?
* How many orders and customers are being served?
* Which cities contribute the most to sales?
* Which product categories generate the highest sales?
* Which payment methods are most frequently used?
* During which time periods are orders highest?
* What proportion of customers are new versus returning?
* How does sales performance change over time?

---

## 📌 Key Performance Indicators

The dashboard tracks the following KPIs:

| KPI                     | Description                         |
| ----------------------- | ----------------------------------- |
| **Total Sales**         | Total revenue generated             |
| **Total Orders**        | Distinct number of orders           |
| **Total Customers**     | Distinct number of customers        |
| **Total Products**      | Distinct number of products/SKUs    |
| **Average Order Value** | Average revenue generated per order |
| **Total Quantity**      | Total number of items sold          |
